# Lokesh Surakasi — Mechanical Engineering Portfolio

A responsive dark-themed personal portfolio built with HTML, CSS, and JavaScript.

## Included sections
- About me
- Skills: CATIA, Autodesk Fusion 360, AutoCAD, Engineering Drawing
- Projects
- Certificates
- Contact and LinkedIn

## Before publishing
1. Open `index.html` and check all details.
2. Add your real profile photo when ready. The current hero panel shows an `LS` placeholder.
3. Replace the certificate placeholders with real certificate details.
4. Review project descriptions and make sure they accurately reflect your actual work and project status.
5. Open `index.html` in a browser to preview.

## Add your photo later
The profile photo is stored in `profile.jpg`. Keep this file in the same folder as `index.html` when previewing or publishing.

## Publish using GitHub Pages
1. Create a GitHub repository, for example `lokesh-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Follow the published URL shown by GitHub Pages.
